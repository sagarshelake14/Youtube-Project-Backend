# 🎬 YouTube Backend – Backend Development Learning Project

A backend-focused **YouTube-like application** developed to learn and practice real-world backend development using **Node.js, Express.js, MongoDB, **.

This project focuses mainly on understanding backend concepts such as authentication, authorization, database design, API development, middleware, file uploads, error handling, and scalable backend architecture.

> **Note:** This project is created primarily for learning and practicing backend development. It is not intended to be a complete clone of YouTube.

---

## 🚀 Features

### 👤 User Management

* User registration
* User login/logout
* User profile management
* Password hashing
* JWT-based authentication
* Protected routes

### 🎥 Video Management

* Upload videos
* Update video details
* Delete videos
* Get video information
* Get all videos
* Video ownership and authorization

### 👍 Likes & Comments

* Like/unlike videos
* Add comments
* Update comments
* Delete comments
* Retrieve video comments

### 📺 Subscriptions

* Subscribe to channels/users
* Unsubscribe from channels
* Manage subscriptions

### 🔐 Authentication & Security

* JWT authentication
* Password encryption using bcrypt
* Authentication middleware
* Authorization for protected resources
* Secure API endpoints

### 📁 File Upload

* Video upload handling
* Image/thumbnail upload
* File processing using Multer
* Cloud-based media storage
